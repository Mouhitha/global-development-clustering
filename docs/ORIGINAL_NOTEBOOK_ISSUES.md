# Historical notebook review

Cell indices are zero-based in `end sem project clustering analysis of global development.ipynb`. The notebook records the historical exploration. The country-level script is a separate analysis, and this review describes what would be needed to interpret or revisit the historical calculations.

## Input and analysis units

- **Cells 1, 3, and 14–17.** Workbook reads use machine-specific Windows paths. A portable entry point should accept a supplied path and select the sheet by name. Cell 3 also summarizes columns based on their stored dtype, which can omit indicators represented by formatted strings.
- **Cells 20–22 and 47.** The notebook creates `Country_encoded` with a label encoder and drops the text country field while retaining the code in the numeric data. Distances in that code reflect arbitrary ordering. Use country labels as group keys and exclude identifiers and the record counter from distance calculations.
- **Cells 26 onward.** The notebook combines numeric cleaning, missing-data handling, outlier filtering, scaling, PCA, K-means, spectral clustering, hierarchical clustering, and DBSCAN. In cells 57–59, the IQR filter drops any row outside a feature's fences. Cells 60 and 104 describe roughly 40% retention in that branch. The exact count was not recomputed. Any recomputation should report the input and retained row counts, their ratio, and which country labels those rows cover.

## Hypothesis tests

- **Cell 8.** The default two-sided one-sample t-test has null `mean health expenditure share = 0.06` and alternative `mean ≠ 0.06`. A small two-sided p-value alone supplies no direction. A prespecified greater-than test would use the alternative `mean > 0.06`, with `mean ≤ 0.06` as the null and the statistic evaluated at the boundary. The 6% value is a hypothesized threshold. A t-test needs a defined sampling unit, independent observations or a dependence-aware analysis, and an adequately normal sampling distribution for the mean.
- **Cell 9.** Urban and constructed rural shares are paired deterministic complements from the same observation. The two-sided paired null would be `mean urban − rural difference = 0`, equivalent to a mean urban share of 0.5 if the shares are exhaustive. An independent-samples t-test uses the wrong variance for these differences. A country-level paired analysis would need independent country differences and an appropriate sampling distribution for their mean. Treating repeated rows within a country as independent would invalidate the row-level test.
- **Cell 10.** The workbook uses `United States`, so filtering on `United States of America` gives an empty group and no valid test. The two-sided F-test null would be equality of the two population variances. With independent normal observations in both groups and valid degrees of freedom, its equal-tail p-value is twice the smaller of the lower- and upper-tail probabilities for the observed variance ratio, capped at 1. The cell doubles the upper tail only. Correcting the label and tail calculation would still leave the dependence and sampling of the repeated country records unresolved.
- **Cell 11.** Neither `Europe` nor `Asia` appears in `Country`, and counts of nonmissing mortality rates are counts of records. A two-proportion null would be equality of the infant death probabilities in defined regional populations. A valid comparison would require a documented mapping to regions, actual death counts and live-birth denominators for comparable periods, and a design that accounts for dependence and supports the large-sample approximation if a z-test is used.
- **Cell 12.** The tested event is an observation's mobile-use value exceeding 0.5. The default two-sided null is that the probability of this event equals 0.5. The printed directional statements do not follow from that test alone. The z approximation requires independent Bernoulli observations with adequate expected counts, so the observation unit and repeated records matter.
- **Cell 13.** The omnibus normality test has null that the sampled energy-use values come from a normal distribution. The usual calibration assumes independent draws, and failure to reject leaves normality unresolved.
- **Cells 14–17.** Each chi-square test has null that the two categorized variables are independent. The pairs are GDP and ease of business, birth rate and infant mortality, birth rate and average life expectancy, and urban share and CO2 emissions, respectively. Row-level repetitions can violate independence of observations. Bin choices and small expected counts also affect validity, particularly when crossing GDP bins with individual ease-of-business ranks. An interpretable test would define the observation unit and bins, check expected counts, and account for multiple tests when drawing joint conclusions.
- **Cell 18.** The handwritten conclusion table records the notebook's interpretations separately from the test cells. A reanalysis with justified tests would generate conclusions directly from the computed statistics and stated alternatives.

## Cluster evaluation

- **Cells 85, 86, 93, 100, 122, 123, 130, 136, 147, 148, 155, 160, and 164.** The notebook compares assignments with centroid proximity or other quantities derived from the fitted labels. These are internal compactness or assignment-agreement proxies. Supervised accuracy would require independent, validated class labels and an evaluation design.
- **Cells 102–104, 138, and 162.** The historical DBSCAN silhouette calls pass the raw labels, which can count noise as a cluster. A silhouette on non-noise samples requires at least two non-noise clusters and more non-noise samples than clusters. Any DBSCAN comparison should also report the non-noise cluster count and the noise fraction. Cell 103 describes DBSCAN as a weaker fit in that historical experiment.
- **Cells 140–162.** The notebook fits clustering methods on two-dimensional t-SNE coordinates. t-SNE is useful for exploring local neighborhoods. Global distances, gaps, and apparent cluster sizes in the embedding can change with the seed and settings, so the plot and scores in its coordinates are exploratory.
